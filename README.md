# Static Website — GitHub Pages Internship Task

A responsive personal learning page built with plain HTML and CSS for free hosting through GitHub Pages.

## Project contents
- `index.html` — website structure and content
- `assets/style.css` — responsive styling
- `docs/INTERVIEW_QA.md` — answers to all seven interview questions in the task brief
- `.gitignore` — ignores common local/editor files

## Preview locally
Open `index.html` in a browser. No build tools, dependencies or paid software are needed.

## Publish with GitHub Pages
1. Create a new public GitHub repository for this task.
2. Upload the contents of this folder to the repository root. Keep `index.html` at the root.
3. Commit and push the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for deployment and copy the live URL shown in Pages settings.

## Updating the site
Edit `index.html` or `assets/style.css`, commit the changes and push to `main`. GitHub Pages publishes the update.

## Technology
HTML5 and CSS3. This is a static site and has no server-side application or database.
